# Security Policy

This demo uses fake data only and runs offline in the browser. It has no server and stores nothing.

## Reporting a vulnerability

Please **do not open a public issue**. Email **favortaueva@gmail.com** with "Y77FAST Digital ID Wallet security" in the subject. Include what you found, where (file and commit), and how to reproduce it. I aim to acknowledge reports within 7 days.

## Scope

`index.html` and the files in this repository.
